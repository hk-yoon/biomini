# Phase I Overview

Phase I is the foundation layer of BioMini.

Its educational narrative is:

```text
simple Python class
        ↓
inheritance and abstraction
        ↓
biological transformations
        ↓
separation of domain and analysis
        ↓
feature engineering
        ↓
machine learning
        ↓
persistence and provenance
        ↓
scientific validation
        ↓
package engineering
```

For the full canonical record, see
[`PHASE_I_COMPLETION_REPORT.md`](../PHASE_I_COMPLETION_REPORT.md).

For learners, Phase I will later be reorganized into a notebook-based course. The
Completion Report is a maintainer/reference document, not the primary student textbook.
